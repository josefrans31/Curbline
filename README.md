# Curbline

A 3D parking game in a single HTML page (Three.js from cdnjs, no build step).

Open `index.html` in a browser to play locally. Pushes to `main` deploy automatically to Netlify at https://curbline.netlify.app.

Note: online free drive only works when the game runs as a claude.ai Artifact. Elsewhere it falls back to solo driving.
